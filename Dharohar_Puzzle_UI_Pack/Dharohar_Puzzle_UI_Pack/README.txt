IMPORTANT
---------
The uploaded artwork is preserved exactly as the master atlas.
It is the visual source for all the UI elements shown in the sheet.

For immediate Godot use:
1. Copy the entire `Dharohar_Puzzle_UI_Pack` folder into the Godot project.
2. Use `Dharohar_Puzzle_UI_Atlas.png` or the file in `Source_Atlas/`.
3. For individual controls, use Godot's AtlasTexture/Region workflow to select the required element from the atlas.
4. Keep filtering disabled for crisp pixel-art edges.

No existing Dharohar game files are included or changed by this pack.
