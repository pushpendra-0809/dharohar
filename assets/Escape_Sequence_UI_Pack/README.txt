# Escape Sequence UI Pack

Dharohar UI pack for the Escape/Pause navigation system.

Aesthetic:
- Ancient Indian / Nalanda-inspired
- 2D pixel/block game
- Minecraft-like chunky visual language
- Parchment + sandstone + terracotta + muted green
- Geometric Indian/temple ornamentation

Files:
panels/escape_panel.svg
panels/confirmation_panel.svg
buttons/button_normal.svg
buttons/button_hover.svg
buttons/button_pressed.svg
buttons/button_yes.svg
buttons/button_no.svg
ornaments/lotus.svg
ornaments/temple.svg
ornaments/indian_border.svg
icons/esc_key.svg

Godot:
- Use the panel SVGs as backgrounds.
- Use button SVGs as visual textures/backgrounds for Buttons.
- Keep button labels as real Godot Button text so they remain accessible and editable.
- For confirmation dialogs, ONLY use YES and NO buttons.
- Suggested import path: res://assets/ui/escape_sequence/
- Suggested CanvasLayer: EscapeSequenceUI

Do not redesign these assets into generic modern UI. Keep the visual language consistent.
