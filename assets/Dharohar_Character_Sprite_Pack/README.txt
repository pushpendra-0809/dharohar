# DHAROHAR CHARACTER SPRITE PACK

One transparent PNG sprite sheet per representative character:
villager, merchant, fisherman, teacher, monk_bhikshu, student_boy, student_girl, special_npc.

Each sheet: 256x80, four 64x80 frames in order:
Down | Left | Right | Up

The surrounding area is transparent; no white background, no white border, and no poster labels/panels.

The supplied poster contains one directional pose per direction, so these are the four available directional poses rather than invented Standing/Walk1/Walk2 frames.

Godot: set Hframes=4 and Vframes=1, or split the sheet into four AtlasTexture/SpriteFrames frames.
